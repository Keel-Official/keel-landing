# Keel landing page

The landing page for Keel, a read-only liquidity risk engine for Stellar. Built with Next.js and MUI in a yarn workspace.

## Run it

1. Use Node 22 (`nvm use 22`), or set `SKIP_NODE_VERSION_CHECK=1` on a newer Node.
2. `yarn install`
3. `yarn dev:web`, then open http://localhost:8082

## Copy

`docs/landing-copy.md` is the source for every line on the page.
